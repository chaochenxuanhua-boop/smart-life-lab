Privacy Policy

Smart Life Lab (スマート暮らしラボ) — Effective Date: January 1, 2026 | Last Updated: November 19, 2026

Smart Life Lab ("we," "us," or "our") operates this consumer gadget and daily convenience product comparison website and its associated first-party automated media publishing system (collectively, the "Service"). This Privacy Policy explains how information is accessed, processed, stored, protected, and deleted when operating our Service and when visitors browse our public website.

1. Use of YouTube API Services

YouTube API Services Disclosure: Our internal first-party publishing and analytics application uses YouTube API Services (specifically the YouTube Data API v3 and YouTube Analytics API) solely to manage, publish, and evaluate video content on the operator's own authorized YouTube channel.

By using or interacting with any YouTube features or embedded/linked content associated with our Service, you acknowledge that Google may process data in accordance with the Google Privacy Policy, available at https://policies.google.com/privacy (also accessible at http://www.google.com/policies/privacy).

2. Data Accessed, Collected, and Stored via Google & YouTube APIs

  • First-Party Channel Operation Only: Our API client authenticates exclusively with the channel owner's own first-party Google OAuth 2.0 account. We do not offer public OAuth login to third-party website visitors or external YouTube users, and we never access private account data belonging to third-party viewers.
  • YouTube Data API v3: Used to upload original short-form videos to the operator's own channel (videos.insert) and inspect public regional trending video categories (videos.list) for non-personal editorial research.
  • YouTube Analytics API: Used to retrieve aggregated, non-personally identifiable channel performance metrics for the operator's own videos (such as view counts, average view duration, average percentage viewed, likes, and net subscriber changes via youtubeAnalytics.reports.query) strictly for internal content quality improvement.
  • Zero Sale or External Sharing of API Data: We never sell, rent, license, trade, or disclose any YouTube API data (authorized or non-authorized) to third parties or external advertising networks.

3. Data Retention, Refresh, and 30-Day Deletion Policy

In strict compliance with Section III.E.4 of the YouTube API Services Developer Policies:

  • Aggregated YouTube API performance summaries used for internal content analysis are refreshed or automatically deleted within 30 calendar days of retrieval.
  • Temporary video rendering artifacts generated during automated publishing are purged immediately upon job completion (and cloud staging buckets enforce an automated 1-day lifecycle deletion rule).
  • If authorization is revoked or data deletion is requested, all stored OAuth credentials and cached API metrics are permanently deleted within 7 calendar days (and under no circumstances retained beyond 30 days).

4. How to Revoke Access to Your Data (Google Security Settings)

In addition to our internal credential deletion controls, any authorized Google/YouTube account holder can immediately view and revoke our application's access to their data at any time via the official Google Security Settings page at:

https://security.google.com/settings/security/permissions

Once access is revoked through Google Security Settings, our application immediately ceases all YouTube API calls for that account and purges any associated cached API records.

5. Website Cookies, Logs, and Search Analytics

  • Static Hosting Logs: Our public web pages are statically hosted via GitHub Pages. Standard technical request metadata (such as IP address, browser user-agent, and timestamp) may be processed by GitHub Pages infrastructure for security and content delivery purposes.
  • Google Search Console: We inspect aggregated organic search query impressions and click-through statistics via Google Search Console to improve article clarity. This data is aggregated and does not identify individual visitors.
  • Cookies & External Merchant Links: When you click an outbound product link to external e-commerce platforms (such as Rakuten Ichiba or Amazon.co.jp), the destination merchant or affiliate network may set cookies in your browser in accordance with their own privacy policies to attribute qualifying referrals.

6. Affiliate Advertising Disclosure

Smart Life Lab participates in affiliate marketing programs, including the Rakuten Affiliate Program, Moshimo Affiliate Program, and the Amazon.co.jp Associates Program. As an Amazon Associate and affiliate partner, we may earn referral commissions from qualifying purchases made through links in our comparison articles, at no extra cost to the buyer. All product comparisons are conducted objectively based on published specifications and practical utility.

7. Data Security Controls

All API credentials, OAuth refresh tokens, and cloud service configurations are restricted via Google Cloud IAM least-privilege access controls and encrypted both in transit (TLS 1.2+) and at rest. Credentials are never exposed in client-side source code or public repositories.
